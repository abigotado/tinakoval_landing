# Журнал решений

Коротко: что решили, почему и что отвергли. Новое решение добавляется снизу с
датой; пересмотренное не удаляется, а помечается «заменено D-N».

## D-1. Astro вместо Flutter Web (2026-10-16)

Статический HTML без JS по умолчанию, встроенная оптимизация картинок, удобные
компоненты. Flutter Web даёт тяжёлый бандл, медленный первый экран на телефоне
и слабое SEO. 11ty — близкая альтернатива, но картинки и шрифты пришлось бы
настраивать вручную. Next/Nuxt/SvelteKit — лишний JS-рантайм ради одной
страницы.

## D-2. GitHub Pages, запасной вариант Yandex Object Storage (2026-10-16)

Pages бесплатен и проще всего в настройке, из Аргентины и остального мира
работает отлично. Из России GitHub в мае–июле 2026 открывался с перебоями
(OONI: до ~16% сбоев), отдельных данных по github.io нет. Поэтому сборка
остаётся переносимой (обычный `dist/`), и при жалобах из России переезжаем на
Yandex Object Storage: в бесплатный лимит лендинг укладывается с запасом.
Cloudflare Pages отвергнут: в России его режут с июня 2025. По Vercel и
Netlify есть жалобы на блокировки.

## D-3. Домен tinaksenia.com (2026-10-16)

Совпадает с Instagram. .com стоит около $10–11 в год без скачка цены при
продлении и не зависит от российских правил регистрации (с 1 сентября 2026 для
.ru нужна учётка на Госуслугах). На индексацию в Яндексе и Google зона не
влияет, регион задаётся в Вебмастере.

## D-4. Gitflow: feature → stage → main (2026-10-16)

Фичевые ветки сквошатся в `stage`, релиз переносит `stage` в `main`
fast-forward'ом и ставит тег. `stage` — ветка по умолчанию, чтобы PR и
обновления безопасности Dependabot шли в неё. `stage` видна на `/stage/` с
`noindex`, чтобы показывать правки до релиза.

## D-5. Простой харнесс (2026-10-16)

Три workflow (ci, deploy, release), правила веток, Dependabot раз в месяц,
`AGENTS.md`. Главный гейт качества — Lighthouse с порогами. Отказались от
gitleaks (в статике нет секретов), html-validate и lychee (Lighthouse
покрывает главное, ссылок мало) и хуков. Причина: это лендинг, простота важнее
витринности.

## D-6. Без форм, аналитики и cookies (2026-10-16)

Запись идёт через мессенджеры. Так сайт не собирает данные сам, не нужен
баннер согласия, а обещание конфиденциальности остаётся честным. Политика
конфиденциальности всё равно есть, потому что переписка — обработка
персональных данных.

## D-7. Шрифты и ресурсы только с нашего домена (2026-10-16)

Google Fonts и другие CDN не используем: в России они могут тормозить, а
обращение к ним раскрывает IP посетителя третьей стороне.

## D-8. Спек-драйвен разработка (2026-10-16)

Требования и критерии приёмки живут в `docs/specs/`, тексты сайта — в
`src/content/ru.ts`. PR сначала правит спеку, ревью проверяет критерии.

## D-9. Дизайн — вариант В1 (2026-10-16)

Все правки собраны в макетах В1 («тихая комната», спокойный и редакционный),
поэтому вёрстка идёт по нему. В2 с анимациями отвергнут: для страницы, куда
приходят в тревоге, спокойный вариант уместнее, и он проще по коду и
производительности. В2 остаётся на канвасе как справка.

## D-10. Единственный контакт — Telegram (2026-10-16)

Номер телефона на сайте не показываем нигде, поэтому нет и WhatsApp. Instagram
тоже убран. Запись только через Telegram: ник @tinakseniya, ссылка `t.me` и
QR-код для тех, кто открыл сайт на компьютере. Так совпадают макеты В1, и не
нужна сноска про Meta.

## D-11. Палитра из макетов В1 (2026-10-16)

Фон `#F1E6C9` и олива `#E4D9B7` вместо бумаги и шалфея из первой редакции
спеки. Владелец утвердил макеты В1 как есть, а эти цвета появились на канвасе
позже, чем был написан §2. Контраст текста и акцента на новых фонах проверен
(WCAG AA).
